# 薯条出海 · FiresGO

用 AI、软件与自动化，帮助中国制造企业更高效地开发海外市场。

我们正在建设一套可复用、可协作、可持续升级的企业出海能力体系，覆盖海外市场开发、数字化获客、AI 内容生产、销售流程和企业运营效率。

## 建设原则

- 一个仓库只负责一个明确领域，避免所有资料堆在同一个大仓库。
- 文案与设计保持关联，同时保留可编辑源文件和可直接使用的导出文件。
- 公共资产统一维护，具体项目独立迭代，通过清晰的目录和版本记录协作。
- 先解决真实业务需求，再把成熟成果沉淀为可复用模板和标准流程。
- 技术与设计最终服务于降低人工成本、提高交付效率和规模化复制。

## 当前重点

- 企业海外市场服务手册与销售资料体系
- 品牌内容和视觉模板沉淀
- 企业数字化获客与客户管理流程
- AI 图片、视频及批量内容生产
- 网站、小程序和内部效率工具
